### 5 Tindakan Terpenting Berikutnya

1. **Review & uji branch `security/p1-remediation` lalu deploy perbaikan P1** yang menutup `APP-ERP-01`, `APP-ERP-02`, `APP-WEB-01`, `APP-WEB-02`, `INFRA-01`, dan `INFRA-02` setelah verifikasi staging.
2. **Hardening Live Cloudflare & Neon (P1/P2):** Aktifkan Cloudflare Access (Zero Trust) untuk `ekalliptus-admin` & matikan subdomain `*.workers.dev`, naikkan `min_tls_version` ke `1.2`, aktifkan HSTS + WAF rate limit untuk `/admin/login` & `/api/*`, set `WEB_ALLOWED_ORIGINS` ketat di Neon Functions, aktifkan `revoke_sessions_on_password_reset: true`, matikan `allow_localhost`, lindungi branch produksi Neon (`protected: true`), dan buat jadwal snapshot.
3. **Audit Live Supabase `muyzxygtlwsfegzyvgcm`:** Jalankan query SQL read-only pada [REMEDIATION_PLAN.md](./REMEDIATION_PLAN.md) di akun Supabase pemilik proyek `ekalliptus-web` dan deploy migrasi RLS `order_sync_failures` + secret `ORDER_WEBHOOK_SECRET`.
4. **Upgrade Runtime & Framework (P1/P2):** Upgrade Node.js lokal & Docker base image (`node:24-alpine` dengan digest) ke `>= 24.22.3` (`CVE-2026-111497` KEV), upgrade `react-router` di `apps/admin` ke `>= 8.5.1`, dan upgrade `astro` dari `6.1.9` ke `>= 6.4.8` (lewati `6.4.7`).
5. **Remediasi Gelombang P2/P3:** Kriptografi verifikasi absensi (`APP-ERP-03`), modul authz & batas ukuran presign upload S3 (`APP-ERP-04`), JWT `alg`/`aud` pinning + hapus `?token=` SSE (`APP-ERP-05`), CSRF `Origin` guard + login rate limit + logout revocation (`APP-WEB-03`, `APP-WEB-05`), dan separation of duties finance/POS (`APP-ERP-06`).
