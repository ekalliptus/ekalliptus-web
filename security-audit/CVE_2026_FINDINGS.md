# Matriks Investigasi CVE-2026 & Advisori Keamanan (SCA)

**Tanggal Pemeriksaan Database Advisori:** `2026-11-24`  
**Metode:** Ekstraksi versi exact dari `package-lock.json` (`erp-ekalliptus`, 399 paket) dan `bun.lock` (`ekalliptus-web`, 761 paket) + versi runtime host (`Node.js v24.19.0`, `npm 11.17.0`, `Bun 1.4.0`), dikorelasikan terhadap **CVE Program**, **NVD NIST**, **GitHub Advisory Database (GHSA)**, **OSV**, dan **CISA KEV Catalog**.  
*(Catatan: `npm audit` sengaja tidak dijalankan agar lockfile tidak ditransmisikan keluar tanpa izin; skor FIRST EPSS ditandai `Not verified` karena API FIRST EPSS tidak di-query secara langsung.)*
